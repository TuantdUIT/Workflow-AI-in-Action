01 Cấu hình ban đầu

3 lớp cá nhân hoá, xếp chồng lên nhau

Hiểu đúng lớp nào làm gì thì sẽ không phải lặp lại context trong mỗi câu hỏi. Mở cấu hình: bấm chữ cái viết tắt tên bạn ở góc dưới bên trái → Settings.

01 Ví dụ điền Profile

Profile & Preferences — điền một lần

Call you
Tên hoặc nickname bạn muốn Claude gọi.
Your work
Ví dụ: "Full-stack developer (frontend, backend, database, big data)".
Preferences
"Trả lời ngắn gọn, ưu tiên ví dụ code thực tế. Stack chính: … . Giải thích khái niệm nền tảng trước khi đi vào nâng cao. Nếu tôi sai, cứ phản biện thẳng."

Styles khác Preferences ở chỗ: preferences là ngữ cảnh/nội dung, còn styles là cách trình bày (Normal / Concise / Explanatory / Formal, hoặc style riêng).

02 Memory

Không phải giải thích lại từ đầu mỗi lần

Memory giúp Claude nhớ context giữa các cuộc trò chuyện khác nhau (sở thích làm việc, dự án đang chạy, quy ước của team).

Cách bật
Settings → mục Memory → bật. Có thể cho Claude tạo memory từ các chat cũ để có sẵn ngữ cảnh.
Bản chất
Claude lưu một bản tóm tắt hướng tới ngữ cảnh công việc — không lưu nguyên văn hội thoại. Bạn xem và sửa được bất cứ lúc nào.
02 Điều nên biết

3 điều cần nhớ

  • Theo từng project — mỗi project có vùng nhớ riêng, không lẫn sang project khác.
  • Search and reference chats — cho phép Claude tìm lại nội dung các hội thoại cũ để tiếp nối mạch làm việc (bật/tắt trong Profile → Preferences).
Thử ngay Sau khi bật, hỏi thử: "tuần trước chúng ta đang làm gì?" để xem Claude nhớ được gì.
03 Projects

Không phải upload lại file mỗi lần mở chat mới

Project gói 3 thứ lại: project instructions (chỉ dẫn đứng sẵn), knowledge base (tài liệu tham chiếu), và các chat nằm trong đó.

Tạo project

  1. Vào Projects ở sidebar trái (hoặc claude.ai/projects)
  2. Bấm New Project → đặt tên
  3. Trả lời "What are you working on / trying to achieve"
03 Instructions & Knowledge

Phần mạnh nhất — và phần ngữ cảnh tĩnh

Phần mạnh nhất

Project instructions

Viết một lần, tự nạp vào đầu mọi cuộc chat. Dùng để đặt vai trò, tone, quy ước, ràng buộc.

Ví dụ
"Bạn là trợ lý code cho dự án X dùng Next.js
+ TypeScript strict + PostgreSQL. KHÔNG
gợi ý đổi framework."

Mẹo: danh sách "KHÔNG được…" hiệu quả hơn liệt kê điều nên làm; tinh chỉnh sau 3–5 chat.

Ngữ cảnh tĩnh

Knowledge base

Bấm nút "+" để tải lên tài liệu, text, code, file… làm ngữ cảnh cho mọi chat trong project.

Enhanced project knowledge (RAG) Claude tìm kiếm trong tài liệu đã upload — chỉ ở gói trả phí (Pro, Max, Team, Enterprise).
03 Lưu ý quan trọng

Điều thường bị hiểu nhầm

  • Các chat trong cùng project không chia sẻ lịch sử tin nhắn; thứ được chia sẻ là instructions + knowledge (+ project memory) — nhờ vậy chạy được nhiều luồng song song mà không lẫn.
  • Số lượng: Projects có trên mọi gói; tài khoản free tạo tối đa 5 project.
  • Team/Enterprise: chia sẻ project với phân quyền Can view Can edit Owner.
Trước khi upload Che/loại bỏ thông tin nhạy cảm (định danh cá nhân, tài chính, credentials) khỏi tài liệu.
04 Claude for Chrome

Từ chatbot thành agent điều khiển trình duyệt

Extension trình duyệt (tên trên store: "Claude in Chrome"): đọc nội dung trang, click nút, điền form, chuyển tab, chạy quy trình nhiều bước — ngay trong phiên đăng nhập hiện tại của bạn.

Cài đặt & bật

  1. Mở Chrome Web Store, tìm "Claude in Chrome" → Add to Chrome
  2. Đăng nhập tài khoản Claude trả phí (Pro/Max/Team/Enterprise)
  3. Pin extension trên thanh công cụ
  4. Cấp quyền; Claude mở trong side panel cạnh trang bạn đang xem

04 Làm được gì & an toàn

Từ tóm tắt trang đến quy trình nhiều bước

  • Tóm tắt bài dài, trích bảng ra CSV
  • Tự điền các trường lặp đi lặp lại
  • Đi qua quy trình nhiều bước: đặt vé, điền form, thao tác trên dashboard bạn đã đăng nhập
  • Cả tác vụ theo lịch
⚠ An toàn — prompt injection Vì Claude hành động với tư cách là bạn trong phiên đã đăng nhập, một trang web độc hại có thể giấu chỉ thị để đánh lừa Claude. Chỉ cấp quyền cho site tin cậy, để Ask before acting cho tác vụ nhạy cảm, và luôn xác nhận hành động rủi ro cao (mua hàng, gửi/đăng dữ liệu, chia sẻ thông tin cá nhân).
05 VS Code extension & CLI

Claude tự đọc, sửa, chạy trong codebase của bạn

Công cụ coding "agentic". Dùng được qua extension VS Code (giao diện đồ hoạ) và CLI (terminal). Cần gói trả phí (Pro/Max/Team/Enterprise) hoặc tài khoản Console — không bắt buộc API key.

05a VS Code extension

Bắt đầu trong VS Code

  1. Cài: mở Extensions (Cmd/Ctrl+Shift+X) → tìm "Claude Code" → Install. Yêu cầu VS Code 1.94+ (chạy được cả trên Cursor, Windsurf, VSCodium…)
  2. Mở: bấm biểu tượng Spark (✱) ở góc phải editor, hoặc ở Activity Bar / Status Bar / Command Palette
  3. Đăng nhập: lần đầu mở panel → Sign in → xác thực qua trình duyệt

05b CLI — cài native binary

Khuyến nghị

macOS / Linux
$ curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell)
$ irm https://claude.ai/install.ps1 | iex
Cách khác — qua npm
$ npm install -g @anthropic-ai/claude-code

Cần Node.js 22+. Vẫn dùng được nhưng đã deprecated cho cài mới — chi tiết ở slide sau.

Lệnh cơ bản
$ claude            # chạy trong thư mục dự án
$ claude --version  # kiểm tra phiên bản
$ claude doctor     # chẩn đoán cài đặt / PATH
05b npm & CLAUDE.md

Lưu ý cài đặt, và "bộ nhớ dự án"

Lưu ý cài đặt Bản npm install -g @anthropic-ai/claude-code vẫn chạy nhưng đã deprecated cho cài mới (yêu cầu Node 22+) — nên dùng native binary. Để gõ claude trong terminal vẫn cần cài CLI standalone (chạy trong integrated terminal của VS Code với Ctrl+`).

CLAUDE.md — "bộ nhớ dự án" của Claude Code

Đặt file này ở gốc repo để ghi quy ước, lện`h build/test, quyết định kiến trúc… Claude tự đọc mỗi phiên. Chỉ ghi thứ thật sự quan trọng — đừng nhồi những gì Claude tự suy ra được.

06 Claude Code + Chrome

Claude Code đọc console/DOM và sửa thẳng code

Không phải copy-paste lỗi qua lại. Claude Code kết nối với chính extension "Claude in Chrome" để điều khiển trình duyệt từ CLI hoặc VS Code.

Yêu cầu

  • Claude Code 2.0.73+ & Claude in Chrome 1.0.36+
  • Gói Anthropic trực tiếp hoặc API key — không qua Bedrock/Vertex/Foundry
  • Chỉ hỗ trợ Chrome & Edge (beta). Chưa hỗ trợ Brave, Arc, WSL
06 Kích hoạt

3 cách bật kết nối trình duyệt

Nơi dùngCách bật
CLIclaude --chrome (bật cho phiên hiện tại). Hoặc gõ /chrome rồi chọn "Enabled by default".
VS Code extensionGõ @browser trong khung nhập, theo sau là việc cần làm.
Kiểm tra công cụGõ /mcp rồi chọn claude-in-chrome để xem danh sách công cụ trình duyệt.
06 Ví dụ prompt debug thực tế

Prompt tự nhiên, không cần cú pháp đặc biệt

Kiểm tra nhanh

@browser mở localhost:3000 và kiểm tra console có lỗi gì không

Kiểm chứng sau khi sửa

Tôi vừa sửa validation của form đăng nhập. Mở localhost:3000, submit dữ liệu không hợp lệ, và kiểm tra thông báo lỗi có hiện đúng không.

Từ lỗi → sửa file

Trình duyệt báo TypeError ở UserList.tsx. Đọc lỗi trong console, tìm file nguồn, và sửa lại với kiểm tra null cho đúng.

06 Cách nó chạy

Chuỗi làm việc điển hình

Claude mở một tab Chrome nhìn thấy được, thao tác theo thời gian thực, dùng chung trạng thái đăng nhập của bạn. Gặp trang login/CAPTCHA, Claude dừng lại nhờ bạn xử lý tay.

  1. Sửa code trong VS Code
  2. Mở app bằng @browser / --chrome
  3. Claude đọc console/network/DOM
  4. Xác định nguyên nhân → sửa file nguồn
  5. Mở lại kiểm chứng

Rất hợp cho debug frontend và các vấn đề giao tiếp frontend–backend.
