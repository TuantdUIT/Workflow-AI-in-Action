01 Khởi tạo & kiểm tra

Bắt đầu một dự án

# biến thư mục thường thành git repo
git init

# xem đang có gì thay đổi — gõ nhiều nhất!
git status

💡 .gitignore — làm ngay từ đầu

Không theo dõi file rác. Với dự án dữ liệu lớn: đừng commit dataset, model hay .env.

Untracked — file mới, Git chưa quản lý
Modified — đã sửa nhưng chưa add
Staged — đã add, sẵn sàng commit

utils.py
02 Local → Remote

Đưa code lên GitHub

git status # có gì thay đổi
git add . # gom thay đổi
git commit -m "feat: ..." # chốt mốc
git push # đẩy lên

🔗 Kết nối remote (chỉ lần đầu)

git remote add origin <url>
git push -u origin main

✍️ Quy ước message (Conventional Commits)

feat: thêm tính năng mới
fix: sửa bug
refactor: chỉnh code, không đổi hành vi
docs: sửa tài liệu
chore: config, dependency...

-u chỉ cần dùng lần đầu cho mỗi nhánh mới — sau đó Git tự nhớ, chỉ cần git push.

03 Nhánh (branch)

Tách nhánh để không đụng main

main phải luôn chạy được. Mỗi tính năng / bug làm trên một nhánh riêng, xong mới gộp lại.

git branch # xem nhánh, * = hiện tại
git checkout -b feature/login # tạo + nhảy vào
git checkout main # chuyển nhánh đã có

🌿 checkout là lệnh đa năng

git checkout -b <tên> — tạo nhánh mới và chuyển vào luôn.

git checkout <tên> — chuyển sang nhánh đã có.

feature/user-profile fix/login-error
03 Merge · trường hợp A

Fast-forward — gộp "tua nhanh"

main chưa có commit mới nào từ lúc rẽ nhánh → Git chỉ cần kéo con trỏ tiến lên. Không tạo commit, lịch sử thẳng tắp.

03 Merge · trường hợp B

Non-fast-forward — gộp 3 chiều

Cả hai nhánh đều có commit mới (đồng đội đã push lên main). Git phải tạo một merge commit M có 2 cha để nối lịch sử — cũng là lúc conflict có thể xảy ra.

04 Pull Request

Merge qua PR — để đồng đội review

Đi làm thực tế: hiếm khi merge thẳng vào main bằng lệnh. Luôn qua Pull Request trên GitHub.

🌿
01

Tạo nhánh

git checkout -b feature/x từ main mới nhất

⬆️
02

Push nhánh

git push -u origin feature/x

🔀
03

Mở PR

base = main, compare = feature/x. Viết mô tả rõ ràng

👀
04

Review

Sửa? Push thêm lên cùng nhánh, PR tự cập nhật

✅
05

Merge

Squash gộp thành 1 commit gọn, rồi xoá nhánh

Dọn dẹp sau khi merge: git checkout main → git pull → git branch -d feature/x
